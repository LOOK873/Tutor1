# งาน: เขียนข้อมูล "โหมดติวเตอร์" ให้โจทย์ชุดหนึ่ง

บริบท: ผู้ใช้เป็นนักศึกษาไทย (Calculus MTH11101/11102 และ Physics) เตรียมสอบ ต้องการหน้าฝึกทำที่ **ไม่เฉลยทันที** แต่ให้ความช่วยเหลือเป็นลำดับ (hint ladder)
โจทย์และเฉลยเต็มมีอยู่แล้วใน `_tutor/src/<key>.json` (รายการของ `{idx, title, steps[{head,body,final}], extras, answer_line}` — title/steps เป็น HTML+LaTeX `$..$` `$$..$$`)
ระบบจะแสดง: 0 แยกโจทย์ → 1 คำถามนำ → 2 หลักการ → 3 ตัวอย่างคล้ายกัน → 4 เฉลยทีละขั้น (ใช้ steps เดิม ไม่ต้องเขียน) → 5 เฉลยเต็ม → สรุป 3 บรรทัด → ข้อฝึกใหม่

## สิ่งที่ต้องเขียน (ต่อโจทย์หนึ่งข้อ)

## กติกาสำคัญ
1. ภาษาไทย กระชับ เป็นมิตร ไม่สั่งบังคับ ("ลองคิดดูว่า…") ใช้ LaTeX ด้วย `$...$` / `$$...$$` (KaTeX) เท่านั้น
2. ในค่า string ที่เป็น HTML **ห้ามใช้ `<` หรือ `>` ดิบ** ในสูตร ให้ใช้ `\lt` `\gt` `\le` `\ge`; ย่อหน้าใหม่ใช้ `<br>`; ตัวหนา `<b>..</b>` ได้
3. h1/h2/h3.demo/mistakes **ต้องไม่เปิดเผยคำตอบสุดท้ายของข้อจริง** (ขั้นกลางที่เป็นหัวใจก็ไม่ควรบอกทั้งหมด)
4. **ข้อฝึกใหม่ทุกข้อต้องตรวจคำตอบด้วยโค้ดจริง** (python + sympy สำหรับคณิต / คำนวณเชิงตัวเลขสำหรับฟิสิกส์) ก่อนเขียนลง JSON — ห้ามเดา ถ้าตรวจไม่ผ่านให้เปลี่ยนโจทย์ฝึก
5. ข้อฝึกต้องไม่ซ้ำกับโจทย์อื่น ๆ ในชุดเดียวกัน และต้องเป็นโจทย์ที่มีคำตอบสวยพอสมควร (เลขไม่ประหลาดเกินไป)
6. ถ้าโจทย์ต้นฉบับเป็นข้อมูลอ้างอิง/ตาราง/ไม่ใช่โจทย์ฝึก (เช่น "ตารางสรุป") ให้เขียน `given/find/concept/summary` แบบสั้น และเว้น `practice` ได้ (ใส่ `"practice": null`)
7. ฟิสิกส์: ใช้ค่า g และหน่วยตามที่เฉลยเดิมใช้ (ดู steps) ระบุหน่วยในคำตอบ
8. เขียนไฟล์ด้วย `json.dump(..., ensure_ascii=False, indent=1)` เพื่อให้ JSON ถูกต้อง แล้วโหลดกลับมาตรวจว่า parse ได้ และมีครบทุก idx ในช่วงที่รับผิดชอบ
9. **ห้ามแก้ไฟล์อื่นใดนอกจากไฟล์ data ของคุณ** (src, render.py, หน้าเว็บเดิม = อ่านอย่างเดียว) ทำงานชั่วคราวใน scratchpad ได้
10. ถ้าไม่แน่ใจโจทย์ข้อไหน (อ่านจากสไลด์/ลายมือกำกวม) ให้เขียน `"flag": "เหตุผลสั้น ๆ"` ในข้อนั้น แทนการเดา แล้วสรุปใน report

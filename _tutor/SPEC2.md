## ไฟล์ที่ต้องเขียน (2 ไฟล์ต่อ partition)
1. **src**: `_tutor/src_parts/<key>_<part>.json` เป็น list ของ
```
{"idx": <int>, "title": "<HTML+LaTeX: โจทย์เต็มรวมทุกข้อย่อย/ตัวเลือก ใช้ <br> คั่น อ่านแล้วไม่ต้องเปิดรูปก็เข้าใจ>",
 "page_imgs": ["ex/ex01.jpg"],   // รูปหน้าที่เกี่ยวข้อง (path ต่อจาก phy/img/) เพื่อให้ผู้เรียนดูรูปประกอบ
 "steps": [{"head":"ขั้นตอนที่ 1: …","body":"<p>…</p>$$…$$","final":false}, ... , {"head":"คำตอบ:","body":"$$…$$","final":true}],
 "extras": [], "answer_line": ""}
```
   - ข้อหลายข้อย่อย (a–e): ทำ step ตามข้อย่อย ใช้หัวข้อ "ข้อ a) …" ข้อ conceptual/อธิบายให้เขียนคำตอบสั้นกระชับ
   - ข้อ "จงแสดงว่า…" ต้องแสดงที่มาจนได้ค่า/สูตรที่โจทย์ระบุ
   - ข้อปรนัย: ใน title ใส่ตัวเลือกครบ; final = ตัวเลือกที่ถูก + ค่า
   - ใช้ค่า g ตามที่โจทย์/ชุดระบุ; ตัวเลขคำตอบสุดท้ายคำนวณด้วย python
2. **data**: `_tutor/data/<key>_<part>.json` รูปแบบตาม SPEC.md ทุกประการ (คีย์ = idx เป็นสตริง) โดยข้อฝึกตรวจด้วยโค้ด

key และ idx:
- `phyex`: idx = เลขข้อ − 1 (ข้อ 1 → idx 0 … ข้อ 24 → idx 23)
- `phymock`: ปรนัยข้อ n → idx n−1 (0–24); ข้อเขียนตอนที่ 2 ข้อ 1 → idx 25, ข้อ 2 → idx 26 (ส่วนต่อยอดท้ายข้อ 25 รวมไว้ใน idx 24)

## กติกา
- ภาษาไทย LaTeX ด้วย `$..$` `$$..$$`, ห้าม `<` `>` ดิบในสูตร (ใช้ `\lt` `\gt`), หน่วยใช้ `\text{...}` และห้ามใช้อักษร `·` ใน `\text{}` (ใช้ `\cdot` นอก `\text{}`)
- เขียนไฟล์ด้วย `json.dump(..., ensure_ascii=False, indent=1)` แล้วโหลดกลับตรวจ
- ห้ามแก้ไฟล์อื่นนอกจากไฟล์ output ของคุณ ทำงานชั่วคราวใน scratchpad
- รายงานสั้น ๆ: เสร็จกี่ข้อ, ข้อที่ flag (อ่านรูปไม่ชัด/โจทย์ขัดแย้ง/ลายมือเฉลยผิด), ข้อที่ค่าในโจทย์ไม่ตรงกับที่คำนวณได้ (เช่น โจทย์บอก t = 3.7 s)
